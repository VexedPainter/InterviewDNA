# InterviewDNA — Data Documentation

## Overview

The file `data/interview_archive.csv` is the core knowledge base for the InterviewDNA system.
It represents a **synthetic 10-year archive (2016–2025)** of campus placement interview records,
designed to mimic the statistical patterns and company-specific DNA of real placement drives
observed at engineering institutions in India.

---

## Anonymisation Policy

> **No real student, candidate, or interviewer data is stored anywhere in this repository.**

All records in `interview_archive.csv` are **entirely synthetic**, generated by
`scripts/generate_synthetic_archive.py` using seeded random sampling and hand-crafted templates.

### What is NOT stored
- Real student names, roll numbers, or personal identifiers
- Real interviewer names or employee identifiers
- Actual transcripts of real interviews
- Any Personally Identifiable Information (PII)

### What IS stored
- Anonymised, synthetic candidate answer summaries (described in third person)
- Synthetic interviewer feedback (template-generated, not from real interviewers)
- Statistical patterns calibrated to reflect realistic company behaviour

### Record IDs
Record IDs follow the pattern `{COMPANY_CODE}-{YEAR}-{INDEX}` (e.g., `TCS-2021-00042`).
These are artificial and do not correspond to any real person or event.

## Schema

| Column | Type | Description |
|---|---|---|
| `record_id` | string | Unique identifier: `{CO}-{YEAR}-{IDX}` |
| `year` | int | Interview year (2016–2025) |
| `company` | string | Company name |
| `role` | string | Role applied for |
| `round_type` | string | Aptitude / Technical / Managerial / HR |
| `topic` | string | DSA / DBMS / OS / Networks / System Design / OOP / Aptitude / Behavioral / Projects / Domain |
| `difficulty` | int | 1 (easiest) – 5 (hardest) |
| `question` | string | The interview question asked |
| `expected_points` | string | Pipe-separated key points a strong answer should cover |
| `candidate_answer_summary` | string | Synthetic summary of the candidate's response quality |
| `feedback_text` | string | Synthetic interviewer feedback in realistic natural language |
| `feedback_tags` | string | Pipe-separated tags describing feedback themes |
| `score_given` | float | Score awarded (0–10) |
| `outcome` | string | Selected / Rejected |

## Generation Details

- **Script:** `scripts/generate_synthetic_archive.py`
- **Random seed:** 42 (fully reproducible)
- **Target rows:** 1,600+
- **Question pool:** 50+ hand-authored questions across 10 topics and 3 difficulty bands
- **Variability sources:** company DNA weights, difficulty distribution sampling, score Gaussian noise, year-based difficulty drift

## Regenerating the Archive

```bash
# Windows
run.bat generate

# Cross-platform
python scripts/generate_synthetic_archive.py
```

## Usage in the RAG Pipeline

Each row is embedded as a document via `scripts/ingest_to_chroma.py` using
`sentence-transformers/all-MiniLM-L6-v2`. Documents are chunked as:

```
Company: {company} | Role: {role} | Topic: {topic} | Round: {round_type}
Question: {question}
Expected: {expected_points}
Feedback: {feedback_text}
Tags: {feedback_tags}
```

This format ensures semantic retrieval returns the most relevant historical records
when a student selects a company + role and asks a question.
